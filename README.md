# EU-Environmental-Pollutants-PCA
PCA on EU Environment data using R

This is a Principal Component Analysis (PCA) project on a Eurostat dataset containing Environmental data from 28 EU member-countries for the years 1995-2015. 

#### An overview of the data:
- Historical data (1995-2015) of 28 EU member-countries
- 8 variables    <img width="1609" height="111" alt="image" src="https://github.com/user-attachments/assets/7a607aa1-4ba7-4bfa-8845-8de87f023913" />

#### Analysis Goal:
The purpose of this analysis was to reduce the dimensionality of the dataset using Principal Component Analysis.
